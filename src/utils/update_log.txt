// Fixed CanyonMath PDF assignment creation bug in AssignmentManager.jsx. Previously, the specific_question_ids array was only being saved to the assignment configuration if the question_source was set to 'specific', causing CanyonMath assignments (which bypass that selector) to save an empty array and throw a "no questions found" error for students. Now, CanyonMath assignments correctly save the selected question IDs. Note: Teachers will need to recreate any broken assignments since the original selections weren't saved in the database.
